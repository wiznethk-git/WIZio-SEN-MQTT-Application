# WIZio-SEN MQTT 设备
欢迎使用 WIZio-SEN MQTT 设备。

开始使用前，请将除 tools/ 文件夹外的所有文件上传至您的设备。

将文件 `mqtt.default.json` 重命名为 `mqtt.json`，并填写您的 MQTT 代理信息。

tools/ 文件夹中包含 dashboard.py 文件，您可以通过它查看和控制设备的外设。<br>
更多详细信息请参阅该文件夹中的 README 文件。

上传完成后，重置设备以启动 MQTT 客户端程序。

如果在上传这些文件时遇到任何语法错误，请尝试重新上传相应文件并重置设备。
随后 `main.py` 应会自动运行。

请访问 [WIZio-SEN MQTT 文档](https://docs.w5500.com/reference/wizio-sen.html#mqtt-device) 获取详细指南。
